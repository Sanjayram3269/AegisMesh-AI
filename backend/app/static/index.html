Governance Multi-Agent Architecture

AegisMesh AI orchestrates 7 specialized agents. IBM Granite 7B serves as the underlying natural language reasoning engine.

1. Planner Agent

Decomposes proposed AI actions into required execution validation checks.

2. Intent Agent

Classifies underlying action intent, data sensitivity, and external exposure.

3. Identity Agent

Validates user role, department clearance, and permissions matrix.

4. RAG Policy Agent

Retrieves policy evidence & clauses from enterprise policy knowledge base.

5. Compliance Agent

Evaluates action against retrieved policies to detect specific violations.

6. Risk Agent

Calculates weighted 0-100 risk score based on 8 core risk factors.

7. Reviewer Agent

Validates decision consistency and triggers human escalation if required.

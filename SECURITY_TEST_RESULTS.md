## 6. How to Reproduce All Results

```bash
# 1. Activate virtual environment
source .venv/bin/activate

# 2. Run complete pytest suite
pytest tests/ -v

# 3. Run mandatory security suite in isolation
pytest tests/test_mandatory_security_suite.py -v

# 4. Generate machine benchmark results
PYTHONPATH=.:backend python3 -c "
from agents.adversarial.benchmark import BENCHMARK_MANAGER
from agents.adversarial.engine import ExecutionMode
for mode in ExecutionMode:
    run = BENCHMARK_MANAGER.run_benchmark(mode=mode)
    print(f'Mode: {mode.value:28} | Attacks Blocked: {run.total_scenarios - run.benign_scenarios - int(run.attack_success_rate * run.adversarial_scenarios)}/{run.adversarial_scenarios} | Latency: {run.median_latency_ms:.2f}ms')
"
```
